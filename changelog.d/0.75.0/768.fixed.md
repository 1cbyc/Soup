- **The MCP evidence-error redactor kept the text between an escaped quote and a real
  delimiter (#758 review follow-up to #768).** `_evidence_error_message` redacts every quoted
  run so an evidence-controlled name cannot reach the MCP transport, but the pattern paired on
  bare quotes. When a value holds **both** quote characters, `repr()` delimits with single
  quotes and backslash-escapes the internal ones; the pairing then slipped by one and the
  evidence text between them survived. Each alternative now consumes an escaped character
  inside the run, so an escaped quote cannot end it.
